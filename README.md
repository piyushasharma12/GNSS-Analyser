# GNSS Analyser — Positioning Accuracy & Signal Analysis

A GNSS analysis project developed to explore satellite navigation data, positioning accuracy metrics, and satellite signal quality through C++ analysis and an interactive web dashboard.

## Overview

The project focuses on analysing GNSS observations and visualizing positioning and signal-quality information. It combines C++-based data processing with a browser-based dashboard.

## Features

- Parse GNSS observations from CSV files.
- Analyse satellite signal strength using C/N₀ measurements.
- Classify signal quality into Strong, Moderate, and Weak categories.
- Compare estimated coordinates with reference coordinates in the dashboard.
- Calculate positioning error statistics, including RMSE, median error, P95, and maximum error.
- Visualize data using interactive charts and maps.
- Export analysis data and reports.

## Technologies Used

- C++
- HTML
- CSS
- JavaScript
- Chart.js
- Leaflet
- CSV data processing

## Project Status

An ongoing learning project focused on GNSS data analysis, positioning accuracy, and visualization.

**Note:** Accuracy results depend on the uploaded data and the quality of the reference coordinates. Demo data should not be interpreted as real-world GNSS validation.
